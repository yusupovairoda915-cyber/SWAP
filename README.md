# SWAP: бесплатный обмен навыками

Два проекта в одной папке:
- `backend/` — сервер на FastAPI (SQLite)
- `app/` — приложение на Flutter

## Что уже есть
- Вход по номеру телефона (+998) и коду из SMS
- Профиль: имя, город, о себе; навыки «могу научить» (с ценой в кредитах) и «хочу выучить»
- Подбор: сначала взаимные обмены, потом остальные
- Обмены без кредитов: предложить, принять, оба подтверждают урок
- Платные уроки: кредиты замораживаются и переходят учителю после подтверждения ученика; кошелёк и история
- Нет по решению основателя (на старте): рейтингов и отзывов

## Запуск сервера
```
cd backend
pip install -r requirements.txt
python -m pytest -q          # 68 тестов, должны пройти
export SWAP_SECRET="длинная-случайная-строка-от-32-символов"
uvicorn main:app --host 0.0.0.0 --port 8000
```
Пока SMS-сервис не подключён, коды входа печатаются в логе сервера.
Для настоящих SMS: `SWAP_SMS=eskiz`, `ESKIZ_EMAIL`, `ESKIZ_PASSWORD` (см. sms.py, перед запуском сверьте с документацией Eskiz).
Если уже создавался файл `swap.db` от старой версии, удалите его.

## Запуск приложения
```
cd app
flutter create .             # создаст папки android/ios, ваши файлы не тронет
flutter pub get
flutter run
```
Адрес сервера задаётся в `app/lib/main.dart` (`apiBaseUrl`).
Для эмулятора Android `http://10.0.2.2:8000` указывает на ваш компьютер.

## Что НЕ проверено
Код ядра (кредиты, профили, обмены, вход) покрыт тестами и проходит. Но FastAPI-файлы (`api*.py`, `main.py`) и всё приложение на Flutter я не запускал: в среде, где они писались, не было FastAPI и Flutter. Возможны мелкие ошибки при первой сборке.

## Перед настоящими пользователями
1. PostgreSQL вместо SQLite (логика та же, SQL почти такой же).
2. HTTPS и лимит запросов по IP на уровне nginx/хостинга (иначе можно слать SMS на чужие номера за ваш счёт).
3. Подключить и проверить Eskiz, согласовать с ними текст SMS.
4. Резервные копии базы: в ней кредиты людей.
5. Политика конфиденциальности и правила: приложение хранит телефоны.
